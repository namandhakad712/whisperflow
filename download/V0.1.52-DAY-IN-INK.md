# WhisperFlow — v0.1.52 "The Day in Ink"

## THE VEIL — the REAL root cause, found and fixed (CDP-proven)
v0.1.51 hardened the grain tile (feImage → plain SVG dots), but the
real-Electron smoke test — NEW this session: launch the actual built app
under Xvfb, drive it with Playwright's Electron API, screenshot the real
BrowserWindow — still read **lum ~118** on every surface. Bisection:
grain off/on identical; even `background: #F7F4EE !important` painted
dark; the only bright pixels were the mouse cursor.

So the dimming wasn't CSS painting — it was **`<html>` itself at
computed opacity 0.5**. Where from? No rule, no inline style, no
animation. DevTools-protocol `CSS.getMatchedStylesForNode` on `<html>`
returned the smoking gun:

```css
:root, [data-grain="subtle"] body::before { opacity: 0.5; }
```

The `:root` selector in that comma list **matches `<html>` itself**.
The whole document painted at 50% opacity, composited over the window's
`backgroundColor: #050505` — a mathematically perfect half-black veil,
exactly what every user screenshot showed. (The grain layer's own 0.5
opacity is why the symptom read as "grain" and misled the first fix.)

**Fix**: selector now targets `body::before` alone. Real-app smoke
re-verified: all four windows bright, **lum 244**. README troubleshooting
entry corrected — both halves of the bug (feImage fragility AND the
`:root` selector) are fixed as of v0.1.52.

## New: the day in ink (DayStrip)
History now opens with the day plotted as a halftone strip: each run an
ink dot sized by its length (4s → 1.6px, 60s+ → 3.2px cap), a 3-hour
ruler (00 06 12 18 24), today's elapsed span as a hairline, hover
tooltip with time · duration · first words. Canvas, dpr-aware,
reduced-motion honored. Verified in the real app with seeded history
through the real IPC bridge — VLM read the card, dots, ruler, and
transcript rows beneath.

## New: onboarding v2 final step
"The console, at a glance" teaches the keys before the first
dictation: `[` collapse, `Alt+1…9` channels, `Ctrl+K` palette — real
keycap styling. VLM-verified.

## BREAKTHROUGH: the real-app smoke harness
`scripts/app-smoke.mjs` — launches the BUILT app (not the dev page)
under Xvfb, waits for the real WindowManager's settings window, seeds
history.json into the real userData dir, drives the real UI (toggle
click, palette), and luminance-checks every shot. This is the test that
would have caught both veil bugs BEFORE shipping. The bisect/paintwalk/
CDP scripts from the hunt are saved alongside as reusable forensics
tools.
