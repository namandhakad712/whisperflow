# WhisperFlow — v0.1.49 "The Front Page"

You brought bestdesignsonx.com and asked for the next level: hero,
loaders, layout, icons, fonts, hierarchy, fluid responsive, backgrounds,
customization, overlay design, live preview windows — don't edit the old,
make it new. Full send. Everything shipped.

## The research

Rendered the bestdesignsonx wall headlessly and ran a VLM pattern
extraction: 15 recurring patterns ranked by frequency (hero glow focal,
serif+italic mixing, chrome-framed live previews, keyboard chips in CTAs,
fanned cards, tiny-meta vs display contrast, fluid breakpoints...).
Adopted ten — every one re-authored in our print language, none copied.

## What's new

### THE FRONT PAGE (new default route `#/home/front`)
- Halftone-plate hero: three ink rings + bayer-dot core, breathing
- 56px+ display: "speak. *it writes.*" — italic accent word
- Decrypting greeting + LIVE engine state ("the press is ready")
- Jumbo pill CTA **that fires a real dictation**, hotkey chip inside
- Micro-meta: model · chars-today countup
- 4-cell bento: recent print runs (fanned rows), press status ([ok]
  states for engine/model/dictionary), today's print run (countups,
  honest empty state), **the six prints as live swatch sheets** —
  one-click apply from home

### THE OVERLAY STAGE (live preview window)
Users finally SEE the capsule before ever pressing the hotkey: a
chrome-framed "desktop" hosting a faithful capsule replica (same
geometry + scope easing) cycling rest / listening / printing /
transcript, with a live mic trace and Engine G mood inks (calm / bright /
storm bloom pads) + voice on/off toggle — on every theme.

### YOUR PRESS (customization)
Density (compact/regular/roomy) · motion (full/calm/still) · paper grain
(off/subtle/full) — data-attrs on `<html>`, localStorage-persisted like
themes, zero IPC change.

### Print loaders
Spinner → **PressLoader** (5-dot halftone warm-up, same API so every
busy state upgraded at once). **PlateSweep** (bayer-dot comet on a 2px
rule) rides model download rows.

### Fluid responsive
Live rail folds to a horizontal strip <1100px · rail collapses to a
64px icon rail <900px · hero title clamp(40→62px) · grids collapse.
