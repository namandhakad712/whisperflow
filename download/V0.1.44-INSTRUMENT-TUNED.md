# WhisperFlow — v0.1.44 "The Instrument, Tuned"

You were right: v0.1.43 was one green used everywhere — no hierarchy, no
color psychology. This release rebuilds the desktop app's visual system
on the discipline used by Raycast/Linear-class apps.

## The diagnosis (measured, not vibes)

Before: the phosphor green #5CE1A9 sat on the active nav, focus rings,
selection, hover text, buttons, badges, pills, marks, palette edges —
roughly 30% of interactive pixels were one saturated green. That's the
"green vomit."

## The new system (docs/DESIGN-v0.1.44.md in the repo)

1. **Luminance-stepped neutrals** — hierarchy now comes from 2-4%
   luminance steps, never hue: bg #07080A → paper #0C0D0F → raised
   #111214 → hover #1B1C1E. Text ramp: #F2F1EE → #9C9C9D → #6A6B6C.
2. **Accent scarcity (60-30-10 rule)** — 60% neutral canvas, 30% text
   and lines, ≤10% color. Measured after: green coverage is 0.1-0.6%
   of pixels (was ~30%).
3. **Semantic color psychology** — every hue means one thing:
   - phosphor green = LIVE signal only (recording LED, active model,
     the hotkey readout, primary CTA)
   - amber = busy/processing
   - violet = AI/polish (the LLM lane)
   - coral = errors/destructive
   - sky = info/links/downloaded
4. **Depth via insets + translucency** — cards carry an inner top-light;
   the command palette is real glass (backdrop blur 12px + gradient
   fill + 1px light border); no outer drop shadows below 24px.
5. **Texture** — 1-bit SVG dither grain on the body (5% whisper),
   corner-bracket card frames (neutral at rest, phosphor on hover).
6. **Both skins** — Daylight rebuilt on the same stepped ramp; WCAG
   verified: primary text 17.3:1, secondary 7.1:1 (AA needs 4.5:1).

## Where you'll see it

Update the desktop app (auto-update, or
https://github.com/namandhakad712/whisperflow/releases/tag/v0.1.44):
- Settings rail: active channel is a neutral raised row with ONE 2px
  green mark — the channel strip reads like hardware, not a highlighter
- Models: active model keeps green (it IS the live lane); everything
  else is ink/sky/violet by meaning
- Command palette (Ctrl/Cmd+K): glass panel, neutral selection edge
- Onboarding: selection cards violet, hotkey card green — the live one

QA: 7 screenshots both skins in download/console-qa/; green-pixel audit
and WCAG ratios measured programmatically.
