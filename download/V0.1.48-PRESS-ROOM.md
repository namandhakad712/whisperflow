# WhisperFlow — v0.1.48 "The Press Room"

You asked why the desktop app still had the old button design, colors,
layout — and pointed at reactbits.dev, canvasui.dev, 21st.dev: the world
already has better components, study them, then make our own. Full
creativity. That's exactly what shipped: the console is completely
redesigned, every screen, every control.

## The research

Mined all three libraries:
- **canvasui.dev**: all 38 components (ascii-sweep, dithered-object,
  ink-object, topographic-object, glyph-rain, decrypt-reveal, canvas
  material, frost, peel...) — half of them already speak our dialect
- **reactbits.dev**: full GitHub catalog — 66 backgrounds, 49 components,
  33 text animations, hooks
- **21st.dev**: 2000+ community components scanned

Then a VLM design critique of our own v0.1.47 console found the real
gaps: dead sidebar space, half-empty content column, no live data anywhere
on screen, weak CTA hierarchy, 28px tabs, zero motion layer.

## The translation

Nothing installed. The grammar of the free world, spoken in our print
language — **the press kit** (9 components, zero deps, all authored):

| Component | Lineage grammar | Our print translation |
|---|---|---|
| PrintButton | specular/shiny buttons | ink floods the label L→R (a roller pass) + specular sweep + stamp press |
| SpotlightCard | spotlight cards | cursor-tracking ink wash that lags like wet ink |
| PillNav | pill/gooey navs | 40px tabs, sliding measured indicator |
| DecryptText | decrypt text | resolves from a printer's charset: ·:•%#%@& |
| CountUp | odometer counters | tabular-num mono digits |
| Magnetic | magnetic hover | 2px lean (print restraint) |
| AuroraField | aurora backgrounds | two-ink lissajous wash at wash-level alpha |
| DotRadar | dot grids | dots grow near the cursor — living paper |
| AnimatedRows | animated lists | 40ms staggered settle per route |

## The new console — "the press room"

- **Three panes**: channel rail (magnetic items) · the sheet (content over
  the aurora, max-width up, cards spotlight, H1 decrypts per route) · the
  **LIVE rail** — halftone mic meter, engine state, model + ready count,
  hotkey, today's chars. Hidden under 1100px.
- **Mic meter never prompts**: only runs when permission is already
  granted — first-run onboarding does the asking.
- **SetupChecklist rebuilt**: full-row interactive, completed rows
  compact with "revisit →", Change buttons are ink-flood plates.
- **Onboarding**: aurora backdrop, decrypt headings on every step.

## The verification loop (VLM audit, all closed)

- aurora not painting → fixed + measured (luminance spread 29.6)
- meter read as a dashed line → fixed + measured (7 distinct bars)
- spotlight → measured localized (26.4 near vs 17.8 far)
- ink-flood on hover → VLM-confirmed
- breadcrumb duplication, tab underline, microcopy contrast → fixed
- 12-shot console harness + 6-theme suite; daylight + onboarding final
  checks: "polished, no defects"
