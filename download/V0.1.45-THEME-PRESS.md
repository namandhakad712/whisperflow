# WhisperFlow — v0.1.45 "The Theme Press"

You asked for the inspiration corpus to actually show up: more themes,
font variety, ASCII design, microanimations. This release is that.

## What shipped

### Six themes, each a print process (settings → Dictation → "the theme press")
| Theme | Sheet | Accent | Display font |
|---|---|---|---|
| **Lab** | near-black instrument | phosphor green | Space Grotesk |
| **Press Room** | warm cream #F7F4EE | print green #0E7A55 | **Instrument Serif** |
| **Night Ink** | deep ink-blue #14171D | cobalt #6FA8FF | **Instrument Serif** |
| **Letterpress** | cold press | vermilion #E8563F | Space Grotesk |
| **Lino** | proofing white | ochre #B56A0F | **Instrument Serif** |
| **Daylight** | studio white | LED green | Space Grotesk |

Every theme is a full token set on the v0.1.44 discipline (luminance-stepped
neutrals, accent scarce) — AND a type cast: the serif themes hand the
display role to Instrument Serif (the SPEC.md editorial register), while
JetBrains Mono stays labels/eyebrows everywhere. The theme decides the
casting, not a global font swap.

### ASCII design
- Every picker card carries the theme's mark in the halftone ramp
  ` ·∙•⦁●` with the accent in the peak glyphs — the website's print-shop
  DNA, in the app.
- The rail's channel numbers scramble-decode on hover (MOTION.md's
  signature): glyph ramp ` .·:;=+x%#@`, settling left→right at 42ms/frame.

### Microanimations
- **Spring toggles** — knobs travel on the `spring` curve (200ms), accent
  fill only when ON.
- **Card lift** — cards rise 1px on out-expo (150ms) + stronger hairline.
- **Theme roll** — switching themes settles the console on `scope` (380ms),
  a soft blur-settle, not an instant flip.
- Standby breath, stage-in cascades, palette stagger all preserved.

### Where to switch
- Topbar button cycles the press
- Ctrl/Cmd+K palette: "theme: Press Room — warm cream…" for all six
- Settings → Dictation → the theme press (with specimens)
- Old lab/daylight choice migrates automatically
