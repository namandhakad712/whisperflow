- **Calendar path (cloud-synced).** `CalendarEvents` table (migration `20260427120000`): PK `externalId`, `title`, `startAtUtc`/`endAtUtc` (BIGINT ms), `conferenceUrl`, `status` ('active'), `notifiedAt` (reminder dedupe; index `calendar_events_due_reminders_idx` on (status,startAtUtc,notifiedAt) serves a 15 s tick). Later columns: `participantNames` (`20260528…`), `colorId`/`selfResponseStatus` (`20260612…`), `prereadTitle/prereadContent` (pre-read brief), `connectorKey` default 'calendar' (`20260819…`), `selfIsOrganizer`, `notetakerCalendarNotice`, `notetakerAutoShare` (`20260929…`), `alternateConferenceUrl`, `seriesKey`, `prereadDispatchedAt`. Synced by `CalendarSyncManager` from **server connectors** (enum `Hs$`: Wispr/Calendar/GoogleAutomations(Gmail)/Outlook/Slack/Notion/Linear/Github/Zoom; prefs `connectorGoogleCalendarEnabled`, `connectorOutlookEnabled`) — calendar events are pulled, not read locally.
- **Live detection ("Automatically detect any call" = pref `autoDetectMeetingsEnabled`, `evaluateAutoDetect()`).** Platform classifier maps bundle-ids (macOS) and `.exe` names (Windows: `zoom.exe`, `ms-teams.exe`, `teams.exe`, `webex.exe`, `wemeetapp.exe`, `slack.exe`, `discord.exe`, `aircall.exe`…) to platforms {`teams`,`zoom`,`webex`,`slack`,`discord`,`facetime`,`gather`,`lark`,`voov_meeting`,`aircall`,`dialpad`…}. Browsers (chrome/edge/safari/firefox/arc…) count only when the URL matches conference domains: `zoom.us|zoomgov.com`, `meet.google.com`, `teams.microsoft.com|teams.live.com`, `webex.com`, `slack.com`, `discord.com`, with code regexes (Meet `[a-z]{3}-[a-z]{4}-[a-z]{3}`, Zoom `j/(\d+)`/`wc/`). Observation features (`AccessibilityWalkFeature`): `active_app_url`, `conference_end_state`, `meet_audio_device`, `meet_page_code`, `meeting_tab_strip`, `native_call_snapshot`, `speaker_bind/discovery`, `teams_audio_device`, `consent_chat`. Analytics: `MeetingDetected`, `MeetingAutoDetectLateLinked`, `MeetingAutoDetectGraceStarted/Elapsed/Cancelled`.
- **Auto-start (calendar-driven join+record countdown):** pref `autoStartNotetaker` / `notetakerAutoStartEnabled`; `autoStartPromptThreshold` (default 3), `autoStartCountdownMs` (default 10000, clamped 5000–60000); countdown state machine armed/paused/cancelled with outcomes `AutoStartArmed/Committed/Failed/Cancelled` (reasons: `clock_jump`, `stalled`, `late_fire`, `handoff`…). Gate refusal reasons: `setting_off`, `flag_off` (feature flag `MeetingRecorder`), `consent_required` (org consent gate decision `request_confirmation`). Manual start from reminder: `CalendarIPC` `StartMeeting` (joinOnly vs join_record; `autoStartSource: "calendar_reminder"`), `Join`, `OpenWispr` actions; `cancelAutoStartForManualStart`.

## 2. Meeting CAPTURE
- **Two audio legs**, captured in the `meeting_recorder` renderer window and written by main: `MeetingAudioBuffer` writes `<meetingsDir>/<meetingId>/mic.pcm` and `system.pcm` (raw PCM, stereo, 256 kB/s), plus `live.pcm`. `meetingsDir` = `join(userData,"meetings")`. **Real path on this machine: `C:\Users\naman\AppData\Roaming\Wispr Flow\meetings\` — exists but empty (no recordings made/kept here).**
- **System audio:** Chromium `session.defaultSession.setDisplayMediaRequestHandler` (`[MeetingDisplayMedia]`): **win32 → `{audio:"loopback"}`** (Electron/Chromium WASAPI loopback, no extra permission beyond mic); darwin → macOS 13+: `screen_capture_kit` (≤14.3) or `process_tap` (≥14.4, `{id:"loopbackAllDevices"}`), exposed to renderer as `macSystemAudioCapability`; **Linux: skipped ("no system loopback path")**. The "Allow … under System Audio Recording in System Settings" string is macOS-only.
- **Mic guards:** loopback/virtual-device blacklist (`blackhole`, `loopback`, `soundflower`, `vb-cable`, `vb-audio`, `cable output`, `zoomaudiodevice`, `microsoft teams audio`, `stereo mix`, `voicemeeter`, `ndi`) so the notetaker doesn't record its own echo; mic "rescue" state machine (`dead_mic`, `same_mic`, `lost_pin_cap`, `ambiguous`, `no_match`, `platform_held`, `mic_final`…), mic pinning + `MicDevicesSnapshot`.
- **Record/stop machine:** monotonic `latestRecordingStopSeq` vs `refinePipelineRanThroughStopSeq`; stop sources include `system_sleep`, calendar end, 1 hr check-in, `notetakerMaxRecordingLength` (default 2 h), semantic auto-stop (`semanticAutoStopPolicy`, `RecordingStoppedSilence`, `MeetingAutoEnded`, `LowConfidenceStopPrompt`); cold-resume re-adopts existing mic.pcm/system.pcm (`hasLivePausedSnapshot`, `bankedAudioMs`, `resumeWindowMs`).
- **Encoding/upload artifacts:** incremental `incrementalOpusEncoder.worker.js` stream-encodes to `upload.ogg` (Opus in OGG, `audio/ogg`), with `.partial` files, fallback to `upload.wav` if Opus fails or WAV would exceed the upload cap; `native-language-evidence.json` (sha256 provenance `soniox_native_final`, recording_id). Uploaded by `RefinementCoordinator` via `AriaWebClient.getMeetingUploadUrl`, multipart, with retry schedules and failure reasons (`network`, `tls_trust`, `too_large_local/413`, `backend_5xx`, `soniox_5xx`, `rate_limited`, `auth`, `cloud_sync_denied`, `unsupported_415`, `read_audio`, `gated`). Recording status window states: `uploading|transcribing|summarizing`.
- **Retention:** `Meetings.transcriptDeletedAt`; transcript retention pref enum {`never_delete`,`1_day`,`7_days`,`30_days`,`90_days`,`180_days`,`365_days`} (default NeverDelete); separate 14-day dictation-audio cleanup (`History.cleanupOldHistory` nulls `audio/opusChunks/builtInAudio`).

## 3. Speaker attribution
Enums (main bundle): **`SpeakerAttributionState`: ["ambiguous","matched","unknown"]; `SpeakerDiscoveryTier`: ["anchored","broad","cached"]; `MeetingSpeakerSourceKind`: ["application_tree","compact_monitor","main_window","meeting_and_compact","meeting_window","none","side_window","single_window"]; `MeetingWindowBindCause`: ["heartbeat","initial","rebind_probe","teams_lazy"]; `MeetingWindowBindOutcome`: ["bound","no_candidates","rejected_no_named_tiles"]; `MeetingMicrophoneMuteState`: ["muted","unknown","unmuted"]; AX tile layouts: ["zoom_main","zoom_compact","zoom_compact_tile","meet_tab","meet_side","teams_main","teams_compact","teams_combined","slack_window","unknown"].**

Flow: a native helper process reads the meeting app's accessibility tree (macOS AX / Windows **UIA** — "reads one top-level UIA window at a time, rebinds to another window of the same call"), binds the window with the most **named participant tiles**, and polls (`StartSpeakerPolling`: `platform`, `targetProcessId`, `tileRootClasses`, `markerClasses`, `anchoredDiscovery`, `collectSpeakerNames`, `observeZoomMuteState`). It emits `MeetingSpeakerChange` events (payload: `attributionState`, `discoveryTier`, `speakerName`, `speakingNames`, `mutedNames`, `participantNames`, `selfName`, `reason`, `source`, `timestamp`). Main records these into an in-memory `AxSpeakerTracker` (binary search `eventAtOrBefore`, stale TTL 1500 ms) and a per-meeting log `<meetingId>/.observations-tmp/<sessionId>.observations.ndjson` (schema `speakers.observations.ndjson`, cap 8 MB). **Pref gate: `notetakerAutoDetectParticipantNamesEnabled` (default 1).** During transcription, mic segments get `speaker={source:"mic"}` (you); system segments get `source:"system"` with name resolved by `systemSpeakerIdentityMap.resolve({speakerId, axStampedName, aliasHintName, recordEvidence})` → `displayName`. Confidence: matched→high, ambiguous→medium, else low. User-facing fixes stored in `Meetings.speakerMap` (JSON `{people, assignments}`), `speakerAssignments`, local-only `speakerAssignmentEdits`, `speakerRoomLabelEdits`.

## 4. Transcript + notes generation (heavily cloud)
Live transcript (`notetakerLiveTranscriptEnabled`) streams per-source — provider chosen by feature flag `meeting-refine-transcription-provider` with zoded payload {primary, shadow, fallback} over providers **"soniox", "wispr-chorus", "open-ai", "other"**. Local cache: `<meetingId>/live.ndjson`. Post-stop refine: upload `upload.ogg`/`upload.wav` → server Soniox webhook → client fetches **`refined.ndjson`**. Refine columns on `Meetings`: `refineStatus`, `refineStopSequences`, `refineRetries`, `refineUploadFailureReason`, `refineFetchRetries`, `currentJobId`. Content model: `Meetings` `id, title, createdAt, modifiedAt, synced, isDeleted, finalized, notes, summary, participantNames, calendarEventExternalId, endedAt, recordedMs, importSource, shareSlug, shareVisibility, summaryReady, transcriptReady…`. Todos: `Todos(id, meetingId nullable, title, status default 'open', isDeleted, isArchived, createdAt, modifiedAt, synced)`. **Automations** `kinds: send_email, add_calendar` (run server-side). Sharing: auto-share pref `notetakerAutoShareNotes`, per-event `CalendarEvents.notetakerAutoShare`, visibility `anyone_with_link|domain|invited_only`; `Folders`/`FolderMeetings` synced via server API.
