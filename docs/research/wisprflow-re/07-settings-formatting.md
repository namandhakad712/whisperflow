## 2. Language model
`getLanguages() = merge(effectiveLanguages ?? selectedLanguages)` — effective (runtime) takes precedence, else selected; if exactly 1 selectedLanguage it is sent as the explicit `language` param to ASR (no auto-detect). usedLanguages = cumulative deduped history of every language ever dictated. "Auto-detect" toggle: "Flow will detect your language automatically. Make sure all the languages you speak are selected." uiLocale/emailLocale app-language overrides.

## 3. Formatting pipeline
Transcription format enum: **"Apply AI formatting"** (default), **"No AI formatting"**, **"Casual messaging"** (capitalize proper nouns only), **"All lowercase"**.
Effective format: `autoCleanup.level==="none" → Raw; else defaultTranscriptionFormat`. Pipeline: TRANSCRIBE → ALIGN always; FORMAT skipped only when effective format is Raw; extra LOWERCASE_SENTENCES step for "Casual messaging"; "All lowercase" lowercases final text. Raw transcripts formatted only when format≠Raw, not command mode, and appType≠"ai".
**autoCleanup levels**: **none / light / medium / high / full**; default "light". Hub picker exposes only **None / Light / Medium** with before/after examples (None: "Transcribes exactly what you said, including mistakes"; Light: "Cleans up filler words and grammar"; Medium: "Edits for clarity and conciseness"). Setting None also sets aiFormatting=false (and non-None ⇒ true) and propagates the level into every userVoice.
**polishInstructions** default: {"Make more concise":!0,"Reword for clarity":!0,"Reorder for readability":!0,"Add structure for readability":!0,"Maintain your tone":!0,"Clarify main point":!1,"Refine phrasing for impact":!1}.
**Auto-detect instruct mode**: internal.isAutoInstructEnabled + flag + appType not AI/terminal → `autoClassify` decides instruction vs dictation (default route "instructShortcut").
**Command mode**: pref commandModeEnabled ("Command Mode — Enable advanced voice commands" + "Press Enter command"). Entered via the **Wispr Lens** hotkey (action `lens`, default Ctrl+Win+Alt on Win) — not the wake word; wake-word triggers ("hey flow","hey flo","hey, flow","hay flow",…,"ask perplexity") are a deprecated path. Transcript routed to `handleQuery`; null ⇒ nothing pasted. Backtrack phrases ["scratch that","never mind","forget that","cancel that","strike that","actually","i mean","no wait","wait no"] delete the last utterance. Press-enter: regex strips trailing "press enter" and simulates Enter after paste.
**Default shortcuts** (action enum: ptt, popo, lens, paste_last_text, copy_last_text, dismiss, command, note, polish, polish_prompt_1..9, gusto_voice, learned_voice, team_voice, person_voice, view_diff, enter_rebind, open_scratchpad, open_meeting_recorder, toggle_focus_mode, toggle_internal_data_sharing, undo): Windows — Ctrl+Win=ptt, **Ctrl+Win+Space=popo**, Ctrl+Win+Alt=lens, Shift+Alt+Z=paste_last, Shift+Alt+X=copy_last, Esc=dismiss; plus default-ensure migrations adding Polish (Win+Alt+1), PolishPrompt1 (Win+Alt+3), ViewDiff (Win+Alt+O), OpenScratchpad (Win+Alt+S), OpenMeetingRecorder (Win+Alt+M), ToggleFocusMode (Opt+F).

## 4. Styles model ("My Voice" / per-app styles)
Legacy `personalizationStyles` {personal, work, email, other → tone} migrated into **userVoices**: map id → Style = {id, source:"builtIn"|"custom", name, appNames:[], autoCleanupLevel, stylePreference(tone)}. Built-ins: work="Work messages" (Slack, Microsoft Teams), email="Email" (Gmail, Microsoft Outlook, Superhuman), personal="Messages" (Messages, WhatsApp, WeChat, Messenger), other="Others" (fallback); all default level "light", preference "formal". Custom styles: id "custom-<uuid>". Matching by app name (normalized) or website in appNames. styleDetectionEnabled (!0, "Style Detection — Automatically set messaging style") auto-selects per app context.
