# Wispr Flow 1.6.1264 — audio pipeline & input/hotkey (RE)

Mic-capture code is NOT in the overlay renderer; the MediaManager lives in `renderer/hub/index.js` (`class cy`). The shortcut engine is `main/index.js` modules 86862 ("Keyboard Service") + 94189 + 28889. The native key/mouse hook is the closed-source helper binary.

## A1 Mic capture
getUserMedia constraints: `audio:{echoCancellation:false, noiseSuppression:false, autoGainControl:false, sampleRate:16000, channelCount:1}` — **16 kHz mono, AEC/NS/AGC all OFF**; deviceId `{exact: selected}`. AudioContext `{sampleRate:16000, latencyHint:"interactive"}`; `audioWorklet.addModule("../dist/recorderWorklet.js")`; `new AudioWorkletNode(ctx,"recorder-processor",{numberOfInputs:1,numberOfOutputs:1})`; `source.connect(node,0,0); node.connect(ctx.destination)`. Worklet: `chunkSize=640`, `renderQuantumSize=128` (5 quanta/chunk), consensus bufferIndex across inputs (desync ⇒ "time indexing into streams is desynced"), per-chunk `port.postMessage({0:buf.slice(0,n), frame:currentFrame+128})` — structured-clone, **no transfer list**. Renderer converts F32→Int16, computes volume dB. IPC `dictation:audioChunk {packet:ArrayBuffer, index, volume, duration:40, encoding:"wav"|"opus"}`. Meeting-mic path differs: `echoCancellation: devMode||{ideal:"all"}`, retry loop toggling AEC if the track label matches `VB-Audio Virtual Cable`.

## A2 Opus
Dictation uses **WebCodecs `AudioEncoder`** probed via `isConfigSupported({codec:"opus",sampleRate:16000,numberOfChannels:1,bitrate:64000})`; each 640-sample input split into 2× **320-sample (20 ms) `AudioData`** frames; encoded chunks sent with `encoding:"opus", duration:20`; flush with 1 s timeout. WAV fallback: Int16 packets, `encoding:"wav", duration:40` (2 synthetic zero-chunks prepended in opus mode).

The two standalone workers are for the **meeting recorder** (post-hoc encode): **opusscript** (npm libopus/WASM) with a **hand-written OGG page writer** (CRC-32 0x04c11db7, OpusHead preskip **312**, OpusTags vendor `"wispr-flow-meeting-recorder"`, maxPageBytes **4096**). Frame = **320 samples/ch = 1280 B stereo**; mic L + system R interleaved. `opusEncoder.worker.js`: read PCM files, encode, write `.opus`. `incrementalOpusEncoder.worker.js` protocol: `incremental_start{micPcmPath,systemPcmPath,partialOutputPath}` → `incremental_ready`, `advance{micBytes,systemBytes}` watermarks → `incremental_advance_result`, `finalize` → `incremental_finalize_result`; reads **256 000-sample** chunks, flushes pages at ≥**262 144 B**, writes `<stem>.<attemptId>.incremental.partial`, packetsPerPage **20**, watchdogs 5 s. Incremental = crash-resilient progressive encode of long meetings.

## A3 Devices
`"default"` sentinel; "Built-in mic (recommended)"; built-in = label has "built-in"+"mac"; bluetooth = airpods/beats; virtual = "(virtual)". `rankedAudioDevices` (user pref `[{deviceId}]`) walked in rank order by `resolveAudioDevice`; fallback to `"default"`; Jabra wear-detection override; clamshell skips built-in. `ondevicechange` → re-enumerate, re-resolve; if recording & chosen device gone ⇒ `MicDisconnected`, **"Active dictation device removed"**, `stopRecording("mic_removed")`; new device ⇒ `RequestNewMicDetected` (buffered while recording). Native helper pushes `media:audioInterruption` (types Began/Ended; reasons deviceDisconnected/defaultDeviceChanged); **"Audio interruption began during active recording"**; 8 s getUserMedia watchdog ⇒ `MicAccessTimeout`; retry backoff [250, 750] ms.

## A4 VAD/endpointing
Renderer-side cheap silence detector — a chunk counts as silent **only if every Int16 sample == 0** (no RMS threshold); `SILENCE_WARNING_THRESHOLD_CHUNKS=125`, `SILENT_START_WARNING_THRESHOLD_CHUNKS=150`, `SILENCE_ESCALATION_THRESHOLD_CHUNKS=375`; chunk = 40 ms ⇒ warn **5 s**, silent-start 6 s, escalate 15 s; logs **"Audio silence bug detected"** (+1 s currentTime stall check), "Sustained silence detected" at 520/1000/2000 ms, **"Audio recovered after sustained silence"** at ≥500 ms; `NoAudioDuringDictation(Escalated)` cleared on recovery. AudioContext: suspended while recording ⇒ `ctx.resume()` + "AudioContext resumed after active suspension"; closed ⇒ "audio data will be lost"; reload via `audioGraphRecovery` (MIN_RELOAD_INTERVAL_MS=3e5, MIN_RELOAD_AUDIO_MS=3e3). **True endpointing is server-side.** Post-release measure (flag `DictationPostReleaseMeasure`): worklet `measure` = 7 blocks of 640 samples posting `postRelease:<dBFS>`; renderer ends hold after **2 consecutive blocks < quietBelowDb**, where quietBelowDb = max(floor, 10th-percentile chunk volume) + quietMarginDb (default **10**, clamped 3…30).

## A5 Caps
At dictation start: `DICTATION_DURATION_WARNING_TIMEOUT=19*60000` ("…one more minute") and **`DICTATION_DURATION_TIMEOUT=20*60000`** → force stop with `forceStopped="max_duration"` + `DictationMaxDurationReached`. Also RECORDING_SAMPLE_RATE=16000, CHUNK 40 ms, baseten chunks 28 s, STREAM_DEADLINE_MS=23 min, TAIL_RECOVERY (6 chunks/60 s/300 s). Notetaker: `notetakerMaxRecordingLength` rungs 30min…6h, absolute 3 h minus 2 min reserve; `internal.maxRecordingLengthMs` override = min(user, 3h−2m).

## B1 PTT/POPO
Helper emits `key_event_press`/`key_event_release` and `mouse_event_press`/`mouse_event_release` with a monotonic `index` (mismatch logged "Electron and Helper do not agree…"). KeyboardService keeps a `Map<keycode, Date>`; matcher with the current chord set. Ptt press ⇒ `startDictation(source)` where source = `Mouse` if any mouse keycode held else `Keyboard`; release ⇒ stop if Listening && !isLocked, with `<DICTATION_DEBOUNCE_DELAY=500 ms` ⇒ `DebouncePTT` dismiss. POPO (hands-free) toggles on **press only**; while locked, releases ignored ("Action up but dictation is locked"); double-press < 500 ms ⇒ `DebouncePOPO`; 3 presses within 500 ms ⇒ triple-tap Notetaker ladder. Hold/tap for OpenScratchpad: hold ≥`SCRATCHPAD_PTT_DELAY_MS=350` ⇒ PTT; double-tap < 500 ms ⇒ POPO. BLE ring control: 1 = PTT start, 2 = stop, 3 = hands-free promotion, 4 = hands-free stop, 5 = newline via `SimulateKeyPress(enter)`.

## B2 Mouse flow
Helper mouse button numbers **2–9** map `{2:mouse_middle(4098), 3:mouse4(4099) … 9:mouse10(4105)}` plus `mouse_aux=65535`; left/right clicks are unmapped and silently dropped (can't be bound). Defaults: **mouse4→POPO, mouse5→EnterRebind** (simulate Enter with held modifiers). Shortcuts use a mouse button instead of a modifier (`validate`: needs modifier OR valid mouse button; ≤3 keys; no left+right pair; blocked list includes cmd+c/v/x/z; "already in_use"). Discovery: `MouseFlowDiscovery` notification after ≥10 transcripts & a connected MX-category mouse.

## B3 Global shortcuts
**Not electron globalShortcut** (only `Alt+K` for FlowFetch). Everything runs through the helper's native event tap (flags: multi-keybind-service, windows-shortcut-masking-v2, windows-key-up-simulation; `keyboard.event_tap_create`, phantom-chord suppression). Matching in JS against `prefs.user.shortcuts` / `cache.splitKeybinds`; keybinds pushed to helper via `UpdateShortcuts`. Capture UI protocol: renderer sends `IsRecording(true)` ⇒ main forwards every raw helper key/mouse event to hub as `Shortcut {keysDown:number[], isRelease}` (tooltip "Click your mouse button to add the shortcut"); onboarding testing modes receive formatted `KeysDown` strings; extension `registerKeybind` supports tap/doubleTap/holdStart/holdEnd with per-keybind holdThresholdMs/doubleTapWindowMs (defaults 350/500). Per-app shortcuts: stashed/unstashed per feature, enterprise hide, blocked-apps list, SecureInput notice. Defaults Win: PTT `Ctrl+Win`, POPO `Ctrl+Win+Space`, Lens `Ctrl+Win+Alt`, paste `Shift+Alt+Z`, copy `Shift+Alt+X`, Dismiss `esc`; Mac: `fn`, `fn+Space`, `fn+Ctrl`, `⌘^V`, `⌘^C`, `esc`. Modifier display order fn<ctrl<cmd<win<alt<opt<shift; modifierShortcut default Win="alt".

## B4 Escape/cancel
Dismiss (default `esc`) fires on **press only**: first calendar-reminder dismissal, then polish diff/context-menu close, clear active notification, dismiss reason `UserActionEscape`; Esc while other keys held ⇒ immediate dismiss + "User dismissed while other keys are held down". Mid-dictation pressing another registered shortcut's keys ⇒ cancel with `DictationCancelledOtherShortcut` ("Dismissing PTT because user is trying to get to other shortcut"). Stale-key sweep every **5 s**, evict held >10 s (helper `CheckStaleKeys`, 500 ms timeout), "Removed stale key … during listening"; chords containing keys held >2500 ms deferred for async verification then suppressed as phantom chords; keypress counters uploaded every 10 000 keys/24 h; typing detectors (100-char sessions, 4 s reset) drive nudges.
