# Wispr Flow (v1.6.1264) — Active-App Detection & Per-App Behavior

## 1. Detection mechanism
Focused-app identification happens in a **native child "helper" process**, not in Electron itself:
- Spawned from main: `O.RA.helper.process=(0,o.spawn)(s,{stdio:["pipe","pipe","pipe","pipe"],...})` (@4553251, `s=(0,f.j)()` = "Helper service script path"; dev error text: `Build it with .\publish-aot.cmd ... in desktop\windows-helper-app\"Wispr Flow Helper"` — a Windows AOT native binary).
- IPC: JSON over stdio pipes. Class `Ze` (`helperClient`) has `static sendRequest(e,t,n)` → `{HelperAPIRequest:...}` via `helperAPIToJson`, a `pendingResponses` map, `defaultRequestTimeoutMs=3e3` (@4532895).
- `getActiveAppInfo = K = () => y("GetActiveAppInfo", e=>e.ActiveAppInfo?.payload, $, {timeoutOverride:300})` with default `$={appName:"unknown",bundleId:"",url:""}` (@4568xxx, module 26181). So identity = **process/bundle id + appName + URL**, returned together.
- The helper also **pushes** `AppInfoUpdate` events (payload `{appName, bundleId, url, foregroundReadTicks}`); main stores `persistentAppContext.lastAppBundleID/lastAppURL/lastAppName` and broadcasts to hub/status windows (@4504441). Textbox context: `GetTextBoxInfo` → `{accessibilityIsFunctioning, beforeText, afterText, selectedText, contents, isEditable, couldNotGetTextBoxInfo}`; also `SetFocusChangeDetectorState`, `DictationStart,{includeOffscreen, captureMarkerContext}` (@4442334).
- Gating: pref `useAxContext:!0` (default); `limitedTextboxContents()` returns null if `!S.RA.prefs.user.useAxContext`, and "Skipping textbox contents for Flow app on Windows (unreliable textbox context)". Enterprise policy disables AX: `(0,l.Xc)(t) → (0,z.xB)({useAxContext:!1})` ("Disabling context awareness per enterprise policy"). OCR path gated by `shouldOCRScreenCapture && useAxContext` → `/llm/ocr` → `ocrParsedWords`.
- Transcript state (reset @4381349): `appName, appBundleID, appURL, appWindowTitle, appType=o.uC.Other, appCodingCliAgent, appContext={conversationId, nearestTexts, axHTML, axParsedWords, ocrParsedWords, screenshot, vsCodeVariableNames, vsCodeFileNames, focusedElementDescription}`. Classification: `a.ZZ.appType=(0,o.getAppType)(a.ZZ.appBundleID,a.ZZ.appURL)` (@4394227). Coding-CLI agent: terminal bundle + window title → `r.includes("claude")?"claude":r.includes("codex")?"codex":null` (@4404131).
- Browser URL deny-list: enterprise `browserUrlDenyList` + `AppDenyListEnforcement` flag (module 47388); URL matched from ActiveAppInfo payload.

## 3. Per-app behaviors
- **Email signature** ("Add a Flow signature when dictating an email"): gated by `getAppType(bundleId,url)===u.uC.Email` (@4396387), feature flag `TOI.EmailSignature` + pref `emailAutoSignature` (settings switch `settings_system_email_signature_label`), local eligibility (greeting `^(hi|hello|hey|dear)[\s,!]` or ≥10 words, no existing "Flow signature" in text/before/after); appends `` `\n\n— ${... Wispr Flow ...}` `` with referral hyperlink when variant `HyperlinkOn`; signature style sent to transcription backend as `flowSignaturePrefix` (WRITTEN/SPOKEN from `emailSignatureOption`) + `flowSignatureHyperlink` (@3800573). Counter `emailWordCount` throttles the upsell (payload limit 250 words).
- **Per-app transcription formats**: prefs `defaultTranscriptionFormat` with enum `$Q={Format:"Apply AI formatting",Raw:"No AI formatting",OnlyCapitalizeProperNouns:"Casual messaging",AllLower:"All lowercase"}`; `appTranscriptionFormats:[]` (per-app overrides) exists as a persisted pref default in main + every renderer bundle — **its consumer is not visible in this build** (sent to server via prefs sync, most likely).
- **Messaging formatting**: trailing-period removal ("Removing trailing period in messaging app", @4297543) keyed off messaging-app detection; capitalization matching uses `appContext.axParsedWords` + first/last name; **Slack @-tagging** (flag `SlackTagging`): replaces teammate names with `@name{{TAB}}` markers using `axParsedWords`.
- **Instruct auto-detect**: `AutoDetectInstructMode` flag + `internal.isAutoInstructEnabled` (dev settings switch "Auto-detect instruct mode"); fires `"autoClassify"` only when `appType!==AI && appType!==Terminal` and not already in instruct/command mode (@4613692); a server-side route classifier then picks Dictation vs Instruct, receiving `app_name, app_url, before/selected/after_text`.
- **AI apps**: auto-cleanup skipped when `appType===u.uC.AI` (@4350204); "textbox already contains ASR text" raw-transcript reformatting suppressed for AI apps (`u=(e,t)=>...&&o.ZZ.appType!==r.uC.AI`).
- **Per-app voice (MyVoice)**: voice chosen by `{appName,bundleId,url}` matching (@4399703); personalization `personalizationAppType` in style config.
- **Contextual nudge / growth heatmap** use `ContextualNudgeAppType` (hub i18n `hub_status_growth_nudge_to_dictate {{appType}}`).
- **Dictation context sent to server** (gRPC, @3640661): `context:{app:{name, bundle_id, type:appType, url}, ax_context, ocr_context, variable_names, file_names, dictionary_context, textbox_contents, content_text(nearestTexts)}` — the taxonomy directly conditions server formatting.

## 4. UIA context-capture architecture (readable `ax-inspect-lib.mjs`, 1500 lines)
`ax-inspect-lib.mjs` is **not** the capture code — it is a dev-only **dashboard/inspector** library (shared by one-shot `ax-inspect.mjs` and long-running `ax-inspect-server.mjs`, both shipped in `resources/`):
- Reads `flow.sqlite` **read-only** via `node:sqlite` `DatabaseSync(dbPath, {readOnly:true})` + `PRAGMA busy_timeout=3000` (WAL-safe against the live app); `fetchRecentRows(dbPath, limit, {decodeNul})`, `fetchRowById`. History columns include **axText/axHTML** (NUL-prone: terminal cells pad with `\0`, so projected as `hex("col")` and decoded back, mapping NUL→space).
- Joins **dev JSONL sidecars** in the logs dir keyed by dictation uuid: `paste-formatting-debug.jsonl`, `proper-noun-debug.jsonl`, `textbox-context-debug.jsonl`, `insertion-verification-debug.jsonl`, `dictation-event-debug.jsonl`, `edited-text-debug.jsonl`, `context-capture-debug.jsonl` (`sidecarTracePaths`).
- In-app launcher (@4269215): forks `resources/ax-inspect-server.mjs` via `utilityProcess.fork(script, ["--port",N,"--no-open","--db",db,"--logs-dir",logs], {serviceName:"ax-inspector-server"})` on an **ephemeral loopback port** allocated with `net.createServer().listen(0,"127.0.0.1")`, then `shell.openExternal`. The HTTP server binds **127.0.0.1 only** ("Loopback only — these pages render local PII"). One-shot `ax-inspect.mjs` forks a `ax-report-generator` utility process writing an HTML report to `os.tmpdir()`.
- What the lib *documents* about the capture pipeline (evidence the UIA side exists in the helper): context-update reasons `REASON_META = {textbox, app_focus, app_context, proper_nouns, cursor_ide, screen_ocr, style_detect, style_undo}` (must match `ContextUpdateReason`); the helper "builds nearestText (nearestTexts) then captures the focused element's markerRange document text, in that order, before sending AppContextUpdate"; TextBoxInfo captures fire on **dictation start, focus change (helper `FocusChangeDetector`), and dictation stop**; insertion-verification verdicts `verified/verified_before_after/not_found/skipped`; DictationStart/`captureMarkerContext`.
- **shouldSaveAxText** (internal pref, default `false`, auto-on when `!app.isPackaged`): gates dev-trace JSONL appends (`appendDevTrace`, module 78935: `!!prefs?.user.internal?.shouldSaveAxText || !app.isPackaged`) and History persistence of raw AX captures (@4388362): `H=async(e,t)=>{shouldSaveAxText&&HistoryManager.updateItem(e,{axText:t})}` and `G` for `axHTML`. `DictationStart` passes `captureMarkerContext: shouldSaveAxText ?? false`.
